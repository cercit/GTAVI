# GTA VI: 9 product decisions

A 9-day product breakdown of the decisions behind GTA VI, one page per day from 11 to 19 November 2026.

## Publishing a day

1. The page is built ahead in `drafts/day-0N.html` (not pushed).
2. On its day, move it to the root and set `live: true` for that day in `days.js`.
3. Commit and push.

Logos go in `assets/` as `rockstar-logo.png` and `gta-vi-logo.png`. Until they're there, the pages show a text wordmark and a sunset graphic.

Independent product breakdown by Sameer Mittimani.
